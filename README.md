# gateways-backend

Standalone backend service for **Gateways** — our CS department's flagship fest website and companion mobile app.

Fastify + MySQL (via Drizzle ORM), replacing the mock localStorage-backed data layer currently in the frontend repo (`Gateways-website`) with a real, shared backend for both the website and the mobile app.

Implementation plan and phased rollout live outside this repo for now, in the team's shared planning doc. Setup and task division happen before implementation begins — this repo currently contains no application code yet.
